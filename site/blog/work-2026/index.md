# Software Developer

I have worked with and built databases:

- Created [DataScript](https://github.com/tonsky/datascript), which inspired a whole series of databases (Datalevin, Datahike, re-db) and powered projects such as Roam Research, Athens Research, Logseq;
- Optimized Firebase-backed storage in [Roam Research](https://roamresearch.com/);
- Built a Postgres-backed DBaaS at [Instant DB](https://www.instantdb.com/).

Sync engines:

- Postgres to browser at [Instant DB](https://www.instantdb.com/);
- DataScript to Datomic at [Cognician](https://info.cognician.com/);
- Helped with [SwarmJS/RON CRDTs](https://github.com/gritzko/ron).

Frontend:

- I’ve been building browser-based apps since 2005;
- Built [my first web framework](https://bitbucket.org/xored/spectre/src) in 2010;
- Created a popular [React wrapper for ClojureScript](https://github.com/tonsky/rum) in 2014;
- Built my own virtual DOM implementation in 2023.

Performance:

- [Fast EDN](https://github.com/tonsky/fast-edn) is 6x faster than Clojure’s standard EDN parser, on par with JSON on JVM;
- Reduced [Roam Research](https://roamresearch.com/) DB load times from minutes to seconds.
