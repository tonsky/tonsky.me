Font coverage audit — current local working tree, 2026-10-31

Scope: 89 published primary blog articles, 6 main pages (Blog, Talks, Logos, About, Work, Subscribe), 19 drafts, 9 translations. All 93 talk versions and their dates/events included. Three old slide HTML entry points inventoried separately.
Fonts: headings and small text = Instrument Sans, IBM Plex Sans, sans-serif; body = Literata, serif; code = Fira Code, monospace.
Method: rendered local HTML, Chromium computed font family/style/weight for text nodes, actual character maps from all 48 local font faces intersected with CSS unicode-range. Checked each style/weight and explicitly declared fallback. NFC normalization for canonical equivalents. Chromium font-selection probes with bundled webfonts explicitly loaded verified A + ring, ANGSTROM SIGN and nonbreaking hyphen are supported through shaping. Ignored layout whitespace, format controls, and variation selectors as standalone glyph requirements. Images, paths in SVGs, embedded videos and external documents are outside this text audit.
Browser verification: browser-verification.json records actual platform fonts for representative strings; system fallback names describe this Mac/Chromium only.

Result: ordinary heading text is covered by the explicit heading stack. Russian talk headings use bundled IBM Plex Sans. Humble State heading arrows and the replacement character example in Unicode also use IBM Plex Sans. Remaining heading fallback: hearts in Sublime/Clojure and Talks, and facepalm emoji in Unicode.
Body: ordinary prose letters are covered, including Russian. Symbol gaps in the shipped Literata files include U+2192 RIGHTWARDS ARROW, U+2194 LEFT RIGHT ARROW, U+21A9 LEFTWARDS ARROW WITH HOOK (generated footnote backlinks), U+2153 ONE THIRD, U+2154 TWO THIRDS, U+2325 OPTION KEY, U+2260 NOT EQUAL TO. Unicode adds U+27F7 LONG LEFT RIGHT ARROW and U+FFFD REPLACEMENT CHARACTER. Shrug faces require U+30C4 KATAKANA LETTER TU. Emoji, upside-down/decorative letters and Zalgo text intentionally need broader fallback.
Logos and About: no uncovered text. Small text: all characters covered by Instrument Sans or bundled IBM Plex Sans.
Code: shipped Fira Code subsets also fall back for arrow symbols, a star, Braille art, and many deliberate Unicode/emoji examples.

Lower-priority content: Chinese and Korean Disenchantment translations require system fonts for their scripts in headings and body. Russian translation is covered by IBM Plex Sans for headings and Literata for body. French, Spanish, Portuguese, Italian and Hungarian Disenchantment translations have no uncovered letters. Spanish Unicode translation repeats Unicode examples.
Drafts: only pl-syntax adds new body gaps: subscript digits ₁₂₆₈, arrows ←→↖↗↘↙ and math ∧∨≠≤≥; draft headings are covered.
Old slides: 2014 Functional Approach to JavaScript uses its own Remark stylesheet and IBM Plex Mono for code. 2015 CodeFest and FrontendConf HTML wrappers use Input Sans Narrow and embedded slide images. These do not use the current heading/body stack; no claim of checking glyphs inside those slide images or external presentations.
